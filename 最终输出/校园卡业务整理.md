# 校园卡业务整理

> 身份：重邮在读学长 · 抖音博主（重邮新生干货）
> 红线：不坐班 · 不售后 · 不处理纠纷
> 产品：中国移动校园卡（主推）+ 中国电信校园卡（备选）
> 核心窗口：7-8月暑假迎新季（黄金期）

## 三、新生必问三大问题

### Q1：为什么要用校园卡？
校园卡是专门给学生群体设计的套餐，流量、通话和资费都比较适合学生。像选课、查成绩、刷慕课、班级群资料下载，校园网络稳定一些会方便很多。提前办好，开学能省不少事。

### Q2：为什么选中国移动？
移动是学校官方独家合作的，网络最稳定。而且我们有校内团队，出了问题直接微信找我，上门给你修，比其他运营商方便多了，不用打长途客服。移动信号为一个独立的基站，而联通和电信共用一个基站，移动网速较好，学校百分之七十的人都用移动校园卡，抢课的时候告别卡顿。

### Q3：为什么要七八月份办？
七八月份是迎新优惠期。提前办好有三个好处：
1. 开学不用大热天排队（去年开学摊位前排了一个多小时队）
2. 能提前了解套餐、激活使用，到学校后直接用
3. 开学后再办可能优惠活动已结束，或要挤在开学高峰办理
4. 暑假办理新生七八月免费用，九月才开始收费

## 四、销售全流程

### 4.1 总流程（5步）

```
建群/引流 → 群内答疑 → 私聊切入 → 推办卡链接 → 记账对账
```

1. **建群/引流**：抖音/小红书发新生干货 → 评论区互动 → 拉新生群
2. **群内答疑**：群内回答新生问题（宿舍/食堂/选课），建立信任
3. **私聊切入**：自然过渡到校园卡话题，四步法建立信任
4. **推办卡链接**：发办理二维码/链接，协助完成下单
5. **记账对账**：记录日期+昵称+手机号+激活状态，月结对账

### 4.2 多平台引流策略

**核心逻辑：** 公域内容引流曝光 → 人设互动建立信任 → 私域沉淀转化变现

#### 渠道一：QQ生态渗透

| 渠道 | 做法 | 注意事项 |
|------|------|---------|
| 官方招生群 | 切入学校官方咨询群、新生群、学院群、老乡群。**复制QQ号再添加好友**，直接通过群聊添加通过率低 | 不要直接在群里发广告 |
| 自己建新生群 | 建2026级重邮新生答疑群，将群号挂在抖音/小红书主页 | 群内禁广告，以答疑为核心 |
| 人设打造 | 打造真实"学长学姐"人设，输出选课、宿舍、社团等实用干货 | 先帮人再谈事 |

#### 渠道二：小红书 & 抖音内容种草

| 平台 | 内容方向 | 具体做法 |
|------|---------|---------|
| **小红书** | 图文攻略为主 | 搜索种草（"重邮宿舍""重邮食堂"等关键词）、决策参考、生活干货、避坑指南 |
| **抖音** | 短视频为主 | 拍校园生活、搞笑段子、抽象视频、吐槽口播，**带重邮定位**更能获得信任 |

#### 渠道三：新生来源挖掘

1. **推荐页捞人**：在推荐页找晒录取通知书的新生，私信联系
2. **评论区截流**：在评论区发现有新生咨询，答疑并添加联系方式
3. **直播间捞人**：在重邮答疑解惑直播间去捞新生；也可以自己开直播

**💡 引流心法：** 利用"官方/学长"身份建立信任，直击新生"怕麻烦、怕踩坑、怕排队"的焦虑点，以"提供便利/避坑"为钩子，自然引导私信。

### 4.3 点对点聊天四步法

**核心原则：先帮人、再谈事。不要一上来就暴露"我是卖卡的"。**

#### 第1步：先解答疑问
对方问什么就先答什么——宿舍、食堂、专业、选课。**不要跳过问题直接推销校园卡。**

> 加人后第一句：「学弟/学妹你好，你是想了解宿舍、食堂，还是开学准备？作为过来人，有啥问题随意问哟～」

#### 第2步：给实用建议
结合对方的专业或地区，给1-2条开学建议。让对方觉得你**真的在帮他，不是机器人客服**。

> 可准备一份"重邮开学必备清单"作为价值输出工具，里面自然包含"办一张校园卡"这一项

#### 第3步：带出用网场景
自然过渡：选课抢课、查成绩、刷慕课、资料下载 → 流量和网络稳定很重要 → 引出校园卡话题。

> 「对了，开学抢课要拼手速+网速，学校的教务系统大家都懂的…校园网稳一点会方便很多。你了解过校园卡吗？」

#### 第4步：自然切入，推办理渠道
对方表现出兴趣后 → 介绍校园卡优势 → 推送办理链接/二维码。

> 「校园卡是免费领取的，迎新季专门给学生准备的套餐。移动这个59的套餐性价比不错，暑假还免费用两个月。需要的话我把办理链接发你～」

**⚠️ 关键区别：** 校园卡的销售节奏比驾校更"轻"——校园卡是免费领取+月租模式，决策门槛低很多。话术更直接、更短、决策更快。不要在一个新生身上花太多时间。

## 五、破冰开场 · 第一句话怎么说

### ✅ 正确示范
- **亲切称呼**："哈喽学弟/学妹你好呀~" — 同辈化的轻松语气，瞬间消除陌生感
- **主动利他**："开学相关的问题都可以问我哦" — 先展现帮助意愿，而非急于推销
- **确认时机**：简单打招呼确认对方是否方便，避免在对方忙碌时打扰

### ❌ 错误示范
- **直奔主题**：上来就问"要不要办卡？" → 极强的推销感，立刻产生警惕和排斥
- **信息轰炸**：直接复制粘贴大段广告文案 → 密密麻麻毫无诚意
- **过度热情**：连环发无关表情包或追问个人信息 → 压迫感，极易被拉黑

**💡 核心洞察：** 私戳的机会往往只有一次，第一句话不是"推销的开始"，而是"连接的起点"。

## 七、常见抗拒处理（9种）

| 抗拒 | 应对思路 |
|------|---------|
| 「移动/联通信号更好吧？」 | 三家都是大运营商。移动是独立基站，学校70%的人用移动。可以问问身边同学实际体验～ |
| 「我再考虑一下/不急」 | 决定权在你。只是越早办好，开学直接激活更方便。怕你开学忙起来忘了去排队～ |
| 「不知道办哪家的好」 | 移动是学校官方独家合作的，售后最方便。你可以几家都了解一下对比一下。 |
| 「我等开学再办」 | 开学也可以，但迎新优惠一般有时限。去年摊位前排了一个多小时队。提前办好更省心。 |
| 「你是不是卖卡的/推销的？」 | 哈哈我主要是给新生答疑解惑的，校园卡只是觉得确实有用才提一嘴。办不办都看你～ |
| 「我流量够用，不需要校园卡」 | 普通流量卡也能用，但校园卡有校园专属权益（宿舍宽带等），套餐也是针对学生设计的。 |
| 「我爸妈让我用家里的副卡」 | 用家里的卡也行。不过校园卡有些校园专属权益，可能副卡享受不到。 |
| 「怕是骗子/不靠谱」 | 可以提供学生证/一卡通证明身份，也可以把移动授权码和套餐详情发给家长看。 |
| 「被推销加了很多次，很烦」 | "太理解了，换我也觉得打扰！我就占用你1分钟，就当了解个校园专属福利，办不办真的没关系～" |

**🚫 核心禁忌：** 不制造焦虑、不诋毁移动/联通、不攻击家长、不虚假宣传套餐权益。校园卡是低频低客单价产品，不值得为一张卡消耗人设信用。**永远不要与对方争辩！先共情再温和解释，把"推销"变成"分享福利"。**

## 八、出卡操作全流程（移动版）

### 标准流程（6步）

```
扫防诈骗码 → 扫办卡码 → 填写信息 → 截图发我 → 拉售后群 → 激活使用
```

### 详细说明

**① 扫防诈骗码（必须第一步）**
办卡之前一定要让新生扫描防诈骗码进行登记。这是给用户的一个保障，也能增加信任度。**这一步不能跳过！**

**② 扫办卡二维码 → 填写信息**
让新生扫码 → 点击右上角三个点 → 用默认浏览器打开 → 点击"订购号卡" → 按步骤填写个人信息。填写完成后，**按"你的名字+新开手机号"的格式**将订单截图私发给你。

> ⚠️ 一定要让新生截图发给你，这是计单凭证！

**③ 拉入售后群 + 激活指引**
客户下单后将对方邀进移动专属售后群。卡包邮到家后按激活流程操作，**注意：签名时签的是"不得非法"，不是签自己的名字。**

### 常见问题解决

| 问题 | 解决方案 |
|------|---------|
| 新生未成年 | 可以先用家长的身份证办理，成年后更换 |
| 身份证上传不成功 | 更换手机设备后重新再试 |
| 外地地址没有选项 | 选择"重庆市" + 客户所在地详细地址 |
| 显示"已达到购买上限" | 下单途中退出 → 重新扫码 → 点击左下角"订单查询" |
| 下单途中退出 | 重新扫码进入 → 点击左下角订单查询 → 继续之前的订单 |

### 📊 计单规则

新生按"你的名字+新开手机号"格式截图发给你 = 算一单。下单后需要重新扫码 → 点击订单查询 → 输入信息确认。**保留截图作为结算凭证。**

## 九、售后与结算

### 售后管理
- 客户下单后**立即拉入移动专属售后群**
- 售后群由移动校内团队统一管理
- 客户有问题在群里直接问，不需要你一个个处理
- 你的角色：售前引流 + 推送办卡 → 下单后拉群 → 结束

### 对账记录模板

| 日期 | 学生昵称/备注 | 手机号 | 来源渠道 | 下单 | 激活 | 预估提成 | 备注 |
|------|-------------|--------|---------|------|------|---------|------|
| 7/15 | 张同学-计算机 | 158xxxx1234 | 抖音私信 | ✅ | 待确认 | — | 已推码 |
| 7/15 | 李同学-通信 | 139xxxx5678 | 新生群 | ✅ | ✅ | — | 已拉群 |

### 与渠道方的关键确认项

1. 单人激活提成多少钱？（首充有没有额外奖励？）
2. 结算节点是下单就算、还是激活才算？多久结算一次？
3. 办理链接/二维码是专属的还是统一入口？怎样确保单量算到我头上？
4. 学生办卡后如果没激活、或者激活后很快销户，还算提成吗？
5. 套餐内容（流量上限、通话分钟数、合约期限）的最新版官方说明在哪儿看？
6. 如果学生投诉套餐问题，渠道方的售后流程是什么？

## 十、合规底线（7条铁律）

1. **不虚假宣传**：套餐、优惠、权益以官方公示为准，不说"无限流量"等未标明的承诺
2. **不诋毁友商**：用事实和自身体验说话，不攻击移动/联通，说"XX也不错"而不是"XX不行"
3. **不攻击家长**：家长有顾虑很正常，建议沟通，**不煽动对立**
4. **不制造焦虑**：不用"不办卡就抢不到课""不办就联系不上同学"等恐吓式话术
5. **保护个人信息**：不随意收集、传播学生个人信息，办卡由学生自己在官方链接完成
6. **合规添加好友**：不频繁骚扰、不刷屏、不复制粘贴同一条评论
7. **售后不越界**：办卡后有套餐/信号/账单问题 → 引导联系官方客服/售后群，不做技术支持

## 十一、与驾校/二手书的协同策略

| 协同场景 | 做法 | 禁忌 |
|---------|------|------|
| 同一新生同时问驾校+校园卡 | 自然回应，分别处理。校园卡决策快可以**先成交校园卡建立信任**，再过渡到驾校 | 不要硬捆绑"报驾校送校园卡" |
| 只问校园卡不问驾校 | 校园卡办完后就结束，**不强行引导到驾校** | 不在校园卡沟通中夹带驾校推销 |
| 只问驾校不问校园卡 | 驾校成交后，可在开学前自然提及"校园卡办了吗？" | 不在驾校话术中夹带校园卡 |
| 二手书交叉 | 如对方主动问教材 → 可自然提二手书；否则不主动推 | 不要三线同时轰炸 |
