# 重邮学长抖音号 · 选题规划 & 内容组合拳

> 账号定位：重邮在读学长 · 新生干货 · 靠谱人设
> 变现路径：软推驾校（九城）+ 二手书
> 目标人群：准大一新生（6-8月）+ 大一在读（9-10月）
> 运营窗口：约1年

---

## 一、内容策略总纲：三层漏斗

```
┌─────────────────────────────────────────────┐
│  第一层：泛吸引（70%）                        │
│  重邮校园干货 · 无植入 · 纯涨粉                │
│  目的：让新生关注你、信任你                     │
├─────────────────────────────────────────────┤
│  第二层：软种草（25%）                        │
│  开学准备/大学生活规划 · 顺带提学车/二手书       │
│  目的：埋下需求种子，让新生主动私信              │
├─────────────────────────────────────────────┤
│  第三层：促转化（5%）                          │
│  学车避坑/经验分享 · 引导私信 · 推代理微信       │
│  目的：成交                                    │
└─────────────────────────────────────────────┘
```

**核心逻辑**：90%的人刷到你是因为想看新生攻略，不是想报驾校。先用干货把人留住，再用软植入筛选意向，最后私信转化。如果一上来就推驾校，号就废了。

## 二、选题库（按漏斗分层 × 发布时间线）

### 时间轴总览

```
6月下旬 → 7月 → 8月上 → 8月下 → 9月开学 → 10月
高考出分   录取   等开学   出发前   报到军训   稳定期
```

### 第一层：泛吸引选题（70%，14条）

#### 选题1：「重邮宿舍长啥样？新生必看」
- **时间**：7月初（录取结果出来前）
- **素材来源**：7.14材料「食宿条件丨重邮食宿条件大揭秘」
- **视频结构**（40-60秒）：
  - 开头（3秒）：拿录取通知书封面的图片，配文字「重邮宿舍到底长啥样？」
  - 中间：快速过一遍宿舍外景→内景→标配设施（空调/热水器/宽带/洗衣机）
  - 结尾：引导互动「还有什么想了解的评论区告诉我，下期拍食堂」
- **是否植入**：❌ 不植入，纯干货
- **为什么有效**：宿舍是新生最关心的问题TOP3，搜索量大

#### 选题2：「重邮7个食堂！哪个最好吃？」
- **时间**：7月初
- **素材来源**：7.14材料「食宿条件」
- **视频结构**（45-60秒）：
  - 开头：7个食堂名称快闪
  - 中间：每个食堂1-2张招牌菜图片+一句话点评（如「中心食堂的三鲜米线，重邮人心中的yyds」）
  - 结尾：「你们最想去哪个食堂？评论区告诉我」
- **是否植入**：❌ 不植入
- **为什么有效**：「吃」是新生最关心TOP3，食堂测评天然高互动

#### 选题3：「一分钟逛完重邮校园」
- **时间**：7月中旬
- **素材来源**：7.14材料「地图册丨沿着重邮的路」
- **视频结构**（50-70秒）：
  - BGM：轻快节奏
  - 路线：腾飞门→三教→图书馆→信科大楼→雨红莲广场→风雨操场→樱花大道
  - 每个地点2-3秒画面+地名标注
  - 结尾：「九月等你来打卡」
- **是否植入**：❌ 不植入

#### 选题4：「重邮新生开学必备清单」
- **时间**：8月上旬
- **素材来源**：自整理 + 7.14营销资料提到的「价值输出工具」
- **视频结构**（40-50秒）：
  - 快速过清单：证件类（身份证/录取通知书/档案）→ 生活类（床帘/插线板/衣架）→ 学习类（电脑/U盘）
  - 结尾：「完整清单截图私信我发你」
- **是否植入**：❌ 不植入，但引导私信（为后续引流埋伏笔）
- **为什么有效**：开学清单=高收藏率=平台推流

#### 选题5：「重邮新生选课避坑指南」
- **时间**：8月下旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 3个选课坑：抢课时间/哪些老师给分高/体育课怎么选
  - 口语化，像一个学长在聊天
- **是否植入**：❌ 不植入

#### 选题6：「重邮周边有什么好玩的」
- **时间**：8月中旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 南山/一棵树观景台/南滨路/火锅店
  - 每个地点一句话推荐理由
- **是否植入**：❌ 不植入

#### 选题7：「军训生存指南·重邮版」
- **时间**：8月下旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 必备物品（防晒/鞋垫/大容量水杯/润喉糖）
  - 军训时间安排
  - 偷懒小技巧（正经向）
- **是否植入**：❌ 不植入
- **为什么有效**：军训=新生最大焦虑源之一，必爆选题

#### 选题8：「重邮大一上学期时间线·每个月该干什么」
- **时间**：9月初
- **素材来源**：个人经验
- **视频结构**（50-60秒）：
  - 9月军训→10月选课稳定→11月期中→12月期末复习→1月考完回家
  - 给一个明确的节奏感
- **是否植入**：❌ 不植入
- **为什么有效**：新生最迷茫的就是「大学该怎么过」，给时间线=给安全感

#### 选题9：「重邮快递点大全·网购不迷路」
- **时间**：9月中旬
- **素材来源**：个人经验
- **视频结构**（30-40秒）：
  - 各大快递点位置+取件方式
- **是否植入**：❌ 不植入

#### 选题10：「重邮有哪些社团值得加」
- **时间**：9月下旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 分类介绍：学术类/兴趣类/运动类/学生会
  - 建议「大一上别加太多，1-2个够了」
- **是否植入**：❌ 不植入

### 第二层：软种草选题（25%，5条）

> 这层是转化的关键——不直接推驾校，但让新生开始思考「我是不是也该学车」

#### 选题15：「大一新生最该做的5件事」
- **时间**：7月下旬
- **素材来源**：代理手册「在校学车优势」
- **视频结构**（50-60秒）：
  - 第1件：熟悉校园，交几个靠谱朋友
  - 第2件：把GPA稳住，大一上别挂科
  - 第3件：加1-2个社团，别太多
  - **第4件（植入位）**：趁大一课少把驾照考了，能加素质学分。后面大二大三忙起来真没时间。我周围大一就拿证的同学都挺庆幸的
  - 第5件：多拍照记录，四年很快
- **植入方式**：5件事里只有1件是学车，比例自然，不突兀
- **为什么有效**：「该做的事」= 新生有决策需求 = 你帮他们做了规划 = 信任

#### 选题16：「开学第一个月要办的事（别漏了）」
- **时间**：8月中下旬
- **素材来源**：自整理 + 代理手册
- **视频结构**（40-50秒）：
  - 办校园卡/宽带
  - 激活学生证/领书
  - 体检
  - **软植入**：「有学车想法的可以趁开学去了解下驾校，开学季一般有活动价，后面就贵了」
  - 选课确认
- **植入方式**：混在一堆待办事项里，像在帮你对清单
- **为什么有效**：新生最容易漏项，这个视频=实用+种草

#### 选题17：「重邮大一新生·一个月的开销大概多少」
- **时间**：8月中旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 吃饭：食堂 vs 外卖，大概1500-2000
  - 日用品+网费+话费
  - 社交和出去玩
  - **软植入**：「如果想学车的话，大概预留3000+的预算，开学季报名比较划算」
- **为什么有效**：家长和新生都关心花销，讲开销的时候顺带提学车预算=自然

#### 选题18：「大学四年最值得考的证」
- **时间**：9月中旬
- **素材来源**：自整理
- **视频结构**（40-50秒）：
  - 英语四六级（必考）
  - 计算机二级（看专业）
  - **驾照（重点植入）**：「大学不考，工作后请假去练车真的痛苦，而且好多岗位现在写着'有驾照优先'」
  - 教师资格证（看意向）
  - 普通话等级（简单顺手考）
- **植入方式**：驾照作为「必考证」之一出现，合乎逻辑
- **为什么有效**：新生对考证有焦虑感和需求感，驾照在这里不是推销品=是正经规划

#### 选题19：「大一最没必要做的几件事（省点时间）」
- **时间**：10月上旬
- **素材来源**：个人经验
- **视频结构**（40-50秒）：
  - 不用急着谈恋爱（顺其自然）
  - 不用加太多社团（1-2个够了）
  - 不用卷所有课（重点课把握好）
  - 不用买太多新书（可以找学长学姐买二手的）
  - **二手书植入位**：「很多教材买新的太贵了，找学长学姐买二手的能省一半，书况还很好」
- **为什么有效**：「没必要做的事」=反焦虑=高好感度，「二手书」在这里不是生意=是省钱建议

### 第三层：促转化选题（5%，1条）

> 这一层严格控制数量。一条就够了，多了号就变味。

#### 选题20：「重邮学车怎么选？学长的真实经历」
- **时间**：7月下旬或8月中旬（在发了5-8条泛吸引内容后）
- **素材来源**：代理手册 + 招生技巧资料 + 7.14营销资料
- **视频结构**（60-90秒）：
  - 开头引出话题（10秒）：
    > 「最近好多学弟学妹私信问我学车的事，我干脆出一条视频说一下。」
  - 讲自己经历（20秒）：
    > 「我当时对比了学校周边好几家，有的报价便宜但后期加钱，有的教练态度差。最后报了九城，到现在练下来整体还行。」
  - 几个选驾校的关键点（30秒）：
    1. 看合同是不是一费到底（别贪便宜）
    2. 看场地离学校多远（练车方便很重要）
    3. 看教练态度（能不能换教练）
    4. 看通过率（驾校都会说高，自己去问学长学姐）
  - 结尾CTA（10秒）：
    > 「有想了解的可以私信我，我把我报的那家负责人微信推你，你自己去问，多对比一下没毛病。」
  - ⚠️ 全程不说价格数字、不说「必选XX驾校」、不踩其他驾校名字
- **这是唯一一条明确推驾校的视频。最多出1-2条类似的不超过总内容的5%。**

## 三、发布时间节奏（组合拳打法）

### Phase 1：抢跑期（6月下旬-7月上旬）关键词：**占坑**

| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第1周 | 选题1「宿舍长啥样」+ 选题2「7个食堂」 | 第一批搜索流量，测内容方向 |
| 第2周 | 选题3「逛校园」+ 选题10「社团推荐」 | 持续涨粉，建立「重邮学长」认知 |

**这个阶段不发任何植入**。新生刚高考完，还没录取，不需要学车。内容重点是「帮他们了解未来学校」。

### Phase 2：信任建设期（7月中旬-8月中旬）关键词：**种草**

| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第3周 | 选题4「开学必备清单」+ 选题15「大一最该做的5件事」 | 清单引导私信；5件事里首次软提学车 |
| 第4周 | 选题17「一个月开销」+ 选题3「逛校园」的精简版 | 开销视频里首次提学车预算 |
| 第5周 | 选题20「学车怎么选」（促转化视频）+ 选题6「周边好玩」 | **唯一一条主推驾校视频**，配一条纯娱乐内容稀释推销感 |
| 第6周 | 选题16「开学第一个月待办」+ 选题7「军训指南」 | 待办视频里再软提学车；军训=焦虑缓解=好感度 |

**关键节奏**：每2-3条纯干货后夹1条软种草。促转化视频（选题20）放在有了一定粉丝基础之后发。

### Phase 3：转化冲刺期（8月下旬-9月中旬）关键词：**收割**

这个阶段新生已经确定要来重邮了，开始做各种开学准备——是学车咨询的黄金窗口。

| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第7周 | 选题5「选课避坑」+ 选题13「图书馆指南」 | 纯干货维持热度 |
| 第8周 | 选题19「大一最没必要做的事」 | 首次植入二手书 |
| 第9周 | 选题18「值得考的证」 | 自然植入驾照 |
| 第10周 | 选题8「大一上学期时间线」 | 纯干货，维持涨粉 |

**这个阶段的重点不是在视频里推，而是在私信里转化。** 经过前两个阶段的内容铺垫，这时候主动私信你说「学长我想学车」的新生会明显增多。

### Phase 4：稳定维护期（9月下旬-10月）

- 维持每周1-2条纯干货
- 不再出新促转化内容
- 偶尔选题19类型的软植入（二手书）
- 重心转移到私信回复和推代理微信

## 四、每条视频的标准操作SOP

### 发布前检查清单

- [ ] 标题有没有包含关键词？（「重邮」「新生」「大一」「宿舍」「食堂」等）
- [ ] 封面有没有大字标题？新生刷到一眼能看懂是什么内容？
- [ ] 有没有引导互动？（评论区问一个问题 / 引导私信 / 引导点赞）
- [ ] 有没有加话题标签？（#重邮 #重庆邮电大学 #大一新生 #开学准备）
- [ ] 植入比例是否超标？（泛吸引期=0植入 / 种草期=1句 / 促转化=整条但不超过总量5%）
- [ ] 语气是不是学长的口语？有没有营销味？
- [ ] 有没有踩合规红线？（不制造焦虑/不虚报数字/不踩其他驾校）

### 评论区运营

- 每条视频发布后24小时内：回复所有评论（前期人少，全回）
- 有人问学车 → 评论回复「私你了兄弟」，转私信按话术处理
- 有人质疑驾校 → 不公开争吵，私信解释
- 有人问其他问题 → 认真回复，体现「真学长」人设
- 有人问二手书 → 回复「私信我帮你找」

## 六、关键数据指标（判断内容对不对）

| 指标 | 正常范围 | 需调整 |
|------|---------|--------|
| 泛吸引内容播放量 | 高于粉丝数3-5倍 | 低于粉丝数 = 选题或标题有问题 |
| 泛吸引内容互动率 | 5%-10%（赞+评+收藏） | 低于3% = 内容不够有用或不够有趣 |
| 软种草内容互动率 | 3%-5% | 低于2% = 植入太生硬，调整话术 |
| 促转化内容评论数 | 至少有3-5条咨询学车 | 0咨询 = 信任没建立够，先回去发泛吸引内容 |
| 私信转化率 | 每100个私信咨询→推代理微信→5-10人最终报名 | 低于3% = 私信话术需优化或推送时机不对 |

## 七、一句话总结

**用重邮干货把新生圈进来 → 用生活建议让他们信任你 → 用一句话软植入让他们主动问 → 私信里把代理微信推过去就完事。**

别想着每条视频都卖驾校。你的价值是「了解重邮的靠谱学长」，驾校只是你顺手推荐的一个选择。人设立住了，流量精准了，转化自然会来。
