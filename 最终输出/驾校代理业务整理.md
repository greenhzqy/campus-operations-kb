# 驾校代理业务整理

> 身份：重邮在读学长 · 抖音博主（重邮新生干货）
> 红线：不坐班 · 不售后 · 不处理纠纷
> 模式：无底薪纯线上提成 · 仅引流+推送微信

---

## 一、合作规则

### 1.1 合作模式：无底薪纯线上提成

| 维度 | 底薪驻点模式 | ✅ 无底薪纯线上提成模式 |
|------|-------------|----------------------|
| 底薪 | 有固定底薪 | **无**，纯按成交提成 |
| 工作形式 | 线下驻点值班、地推发传单、举牌、带看场地 | **纯线上**，只做引流+推送微信 |
| 时间投入 | 全天候（手册原文：早10点站到晚10点） | 碎片化，极低 |
| 售后责任 | 需跟进学员全过程、维护关系 | **零售后**，推送即结束 |
| 提成 | 底薪 + 较低提成 | 纯提成，比例相对更高 |

**我的选择：无底薪纯线上提成模式。** 核心价值是抖音精准新生流量，不是线下执行力。一年运营窗口期，不值得建立重资产合作。

### 1.2 驾校定价体系

| 班型 | 包含内容 | 参考价 |
|------|---------|--------|
| **普通裸价班** | 入学费+培训费+体检费+接送费+考试费+保险费+制卡费+复训费 | 不含补考+合场 |
| **全包班** | 上述全部 + 补考费 + 合场费（部分校区不包合场） | **3000元+** |

#### 各项费用明细

| 合场费（科二+科三各1h） | 780 元 |
| 补考费（科一） | 25 元 |
| 补考费（科二） | 160 元 |
| 补考费（科三） | 180 元 |

| 老学员推荐奖励 | 500 元/人 |
| 科一学时（线上+线下） | 990 分钟 |

### 1.3 提成结算

> 「报名费先交给代理后去掉提成再转到公司财务，报名费可以不用经过客服，但是会向公司财务查账。」

| 收款方式 | 金额 | 是否入学籍 | 是否计提成 |
|----------|------|-----------|-----------|
| 定金 | 500 元 | ❌ 不入学籍，仅开收据 | 不计 |
| 入学籍 | 3020 元 | ✅ 发资料办理 | 可能部分 |
| **全款** | 全款 | ✅ 签合同入学籍 | ✅ 当场拿提成 |

**提成要点：**
- 代理提成具有「自我调节性」——可自行让利做活动，让利部分从提成中扣除
- 团队抽成：「团队其他人出单时，你都可以从这一单身上抽成」
- 建议结算日：**每月5号**，以**全款到账**为结算节点
- 对账凭证：保留每次推送代理微信的**截图+时间戳**

### 1.4 权责划分

| 环节 | 我（引流方） | 代理方（驾校） |
|------|:-----------:|:-----------:|
| 抖音内容制作发布 | ✅ | — |
| 私信/评论初步互动 | ✅ ≤5轮对话 | — |
| 推送代理微信给学员 | ✅ 一次搭桥 | — |
| 记录备案（对账用） | ✅ 简单记录 | — |
| 驾校详细介绍、精准报价 | — | ✅ |
| 带看场地、试驾体验 | — | ✅ |
| 签合同、收费开收据 | — | ✅ |
| 入学籍、安排教练 | — | ✅ |
| 学员跟进、催单 | — | ✅ |
| 投诉处理、纠纷调解 | — | ✅ |
| 退费、换教练 | — | ✅ |
| 提成结算支付 | — | ✅ 代理方主动结算 |

**🔴 免责红线（必须写入合作协议）：**
1. 本人仅提供学员首次微信推送，**不参与任何后续环节**
2. 学员与驾校之间的合同、费用、服务纠纷，**与本人无关**
3. 本人不对代理方的口头承诺、报价、服务质量承担**任何连带责任**
4. 学员投诉至本人 → 仅转发代理微信，**不做调解、不承诺、不赔偿**

## 二、极简引流全流程

```
发内容 → 回私信 → 推微信 → 记账
(4步走完，无第5步)
```

1. **发内容**：抖音发新生干货，软植入驾校信息
2. **回私信**：≤5轮简短沟通，判断基本意向
3. **推微信**：直接推送代理微信名片
4. **记账**：日期+昵称+推给谁，月底对账用

### ✅ 只做这些
- 抖音发新生干货，软植入
- 私信简短互动后推微信
- 口语化学长风格回复
- 简单记录对账

### ❌ 打死不做
- 不发传单、不举牌、不地推
- 不群发私戳推销
- 不带看场地、不陪报名
- 不问「考虑得怎么样了」
- 不建学员群、不维护关系
- **不碰钱、不碰合同**

## 三、点对点聊天四步法（驾校版）

**核心：先帮人、再谈事。**

### 第1步：先解答疑问
对方问什么就先答什么——宿舍怎么样？食堂好吃吗？专业怎么选？选课有什么坑？**不要跳过问题直接推销。**

> 🎯 驾校场景：新生问的是开学、选课、宿舍——就答这些，别提学车

### 第2步：给实用建议
结合对方的专业或地区，给1-2条开学/大学生活的小建议。让对方觉得你**真的在帮他，不是机器人客服**。

> 🎯 「对了，大一课少，很多同学会趁这学期把驾照考了，后面大二大三忙起来就没时间了」

### 第3步：带出学车场景
自然过渡：课余时间怎么利用？加素质学分有什么途径？——引出学车这件事，**但不直接推驾校**。

> 🎯 「大学课余时间挺多的，好多同学大一就把驾照拿了，还能加素质学分。你是打算在校学还是回家学？」

### 第4步：自然切入，推微信
对方表现出兴趣后 → 分享自己的学车经历 → 推荐咨询渠道 → 推送代理微信。

> 🎯 「我自己报了九城，目前体验还不错。你要了解的话我把他们负责人微信给你，你自己问，比我在中间传话靠谱。多对比一下没毛病👍」

**⚠️ 关键原则：** 不要一上来就暴露"我是推驾校的"。先帮对方解决实际问题，建立信任后再自然过渡。你是**内容引流被动获客**，不是主动推销。

## 四、全套学长风格话术

### 场景1 · 评论区有人问「重邮学车去哪好」

**评论区回复：** "私你了兄弟"

**转私信后：** "学车坑挺多的，我去年对比了一圈最后报了九城，目前体验还行。你自己也多了解下，我把他们负责人微信给你，你直接加他问就行 👉 **【推送名片】**"

### 场景2 · 私信问价格

"价格我不说死了哈，不同班型不一样，而且有时候有活动价。你加他们负责人微信让他给你报个价，你就说学长推荐的 👉 **【推送名片】**

报价单可以截图给我帮你看看合不合理～"

### 场景3 · 担心隐形消费、教练态度、练车距离

"哈哈我当时也怕这个😂 我室友在家学被教练阴阳怪气惨了。九城这边教练是提成+淘汰制，态度不行的会被换掉，这个我确认过。

费用的话合同里会写清楚一费到底，后期不收杂费。你加他让他把合同模板发你看看 👉 **【推送名片】**

反正问清楚再决定，别急，多对比一下没毛病👍"

### 场景4 · 团报优惠、拿证时间、练车安排

"团报有优惠的，具体看人数。拿证正常一两个月，快的一个多月也有。

练车提前一天约时间，不会和上课冲突，一人一车一教练，这点挺舒服。团报价你直接问他 👉 **【推送名片】**

提学长名字说不定额外照顾一下哈哈🤝"

### 场景5 · 🔴 学员报名后不满/投诉/纠纷 —— 「甩锅不调解」

**版本A · 教练态度问题：**
"啊这样…不好意思让你体验不好😥 这事我确实没法直接处理，我只是帮忙推荐的。你直接找驾校负责人反映效率更快 👉 **【推送微信】**"

**版本B · 收费争议：**
"费用的事我不清楚最新政策，我这边没经手任何费用。你直接联系驾校财务或负责人核实 👉 **【推送微信】**"

**版本C · 要求退费：**
"退费我处理不了哈，钱没经过我。你直接找驾校走正规流程，该退他们会退的 👉 **【推送微信】**"

**版本D · 对方情绪激动/纠缠不休：**
"理解你的心情。但我真的只是帮忙介绍了一下，合同和费用都是你和驾校之间的事。你直接找他们负责人沟通，他们必须给你一个说法。我帮你转达不如你自己直接找他们效果好。"

**四字原则：** 共情 → 划界 → 推微信 → 闭嘴。绝不承诺「我帮你说说」。

## 五、常见抗拒处理（6种）

| 抗拒 | 应对思路 |
|------|---------|
| 「这驾校没听过/不靠谱吧」 | 我自己对比了好几家最后选了九城，目前体验下来还可以。你也可以问问身边报了驾校的同学实际感受，兼听则明～ |
| 「我再考虑一下/不急」 | 当然可以，决定权在你。只是大一课少、时间多，是学车的黄金期。到了大二大三忙起来真不好挤出时间。你慢慢考虑，有疑问随时问～ |
| 「不知道选哪家驾校好」 | 各有特点，主要看你看重什么。如果看重费用透明、教练态度、练车方便，我报的九城性价比还不错。你可以几家都问问对比一下。 |
| 「我等开学再说」 | 开学也行，但开学季报名的人多，教练排期会比较紧。现在提前了解清楚，开学直接办，能省不少排队时间。 |
| 「你是不是推销驾校的？」 | 哈哈我主要是给新生答疑的，学车只是我觉得确实有用才提一嘴。报不报都随你，交个朋友也行～ |
| 「我爸妈让我回家学/我不需要」 | 理解～很多同学一开始也这么想的。但家里寒暑假是旺季，排队久、天气差，万一挂科要拖到下一个假期。你可以先了解一下在校学的方案，对比一下不亏。 |

**🚫 核心禁忌：** 不制造焦虑（不说"不报就怎样"）、不诋毁其他驾校、不攻击家长、不虚假宣传。代理手册里的「威逼利诱」（用改革难度翻倍吓学员）**踩线了**，建议弱化为客观提醒。

## 六、风险避坑总结

### 💰 结算风险

| 风险 | 规避方法 |
|------|---------|
| 代理不认账「这学员是我自己招的」 | 每次推送保留截图+时间戳，对账当凭证 |
| 学员只交定金，提成悬空 | 协议写明「全款到账才算」，定金不提成 |
| 代理拖欠、耍赖 | 固定每月5号结算，超期暂停推送新学员 |
| 单子少不单独结算 | 协议写死「不论单量，有就结」 |

### 🗣️ 学员口碑风险

| 风险 | 规避方法 |
|------|---------|
| 驾校服务差→学员怪我推荐 | 话术永远说「我体验还行，你自己也要考察」，不给绝对背书 |
| 代理乱承诺→学员找我对质 | 绝不转述代理的任何承诺，把责任推回代理方 |
| 评论区公开骂我 | 公开回「私你了」，私下按场景5处理，不公开撕 |

### 📱 账号人设风险

| 风险 | 规避方法 |
|------|---------|
| 变成驾校推销号→掉粉 | 驾校内容≤10%，主发新生干货，只软植入 |
| 回复太商业化→学长人设崩塌 | 口语化、带表情、不用营销字眼 |
| 合作到期后人设绑定 | 不把驾校名写进ID/简介，到期删植入即可 |

### ⚔️ 业务冲突风险

| 风险 | 规避方法 |
|------|---------|
| 代理施压我通过他们渠道推校园卡 | 明确「校园卡我有独立合作渠道，不通过驾校代理方做」，写进协议 |
| 代理要我建团队 | 拒绝——团队管理需要大量投入，违背纯引流定位 |
| 代理要我线下站台 | 协议写死「仅线上引流」，线下要求一律否决 |
| 其他驾校也来找我 | 可多家合作但保持透明；同一学员不同时推多家 |

## 八、合规底线（7条铁律）

1. **不虚假宣传：** 价格、通过率、拿证时间等以驾校官方公示为准，不说"包过""必过"
2. **不诋毁友商：** 用事实和自身体验说话，不攻击、不点名、不传播其他驾校负面信息
3. **不攻击家长：** 家长有顾虑很正常，建议沟通，不煽动对立
4. **不制造焦虑：** 不用"不报就涨价""改革变难""不学就吃亏"等恐吓式话术 ⚠️ 原手册踩线
5. **保护个人信息：** 不随意收集、传播学员个人信息，推送代理微信前征得对方同意
6. **合规添加好友：** 不频繁骚扰、不刷屏、不复制粘贴同一条评论，遵守平台规则
7. **不碰钱不碰合同：** 任何费用由驾校直接收取，合同由驾校与学员直接签署

## 九、谈判必问清单（15问）

### 提成 & 钱
1. 全包班和普通班，单人直推提成各是多少？
2. 有没有阶梯提成？（月≥5人上浮？≥10人？）
3. 二手书提成怎么算？按售价百分比还是固定金额？
4. 每月几号结算？月结还是周结？
5. 学员交定金后来没补尾款，算我的吗？
6. 你们怎么标记「这个学员是学长推来的」？

### 权责 & 边界
7. 能出一份简单书面确认吗（微信文字也行）：明确我只做引流+推送+不售后+不担纠纷责任？
8. 学员找你们投诉，你们会不会说「你找那个学长去」？
9. 二手书物流、退换、质量纠纷谁负责？（必须你们）
10. 合同谁签？钱谁收？（必须你们，我绝不碰）

### 排他 & 冲突
11. 要求我独家推九城吗？我要同时推其他驾校，接不接受？
12. 学员如果之前咨询过九城（其他渠道），最后报名算谁的？
13. 校园卡我有独立渠道自己做，不通过你们做校园卡，能不能接受？

### 退出 & 保护
14. 我提前停更/毕业，已推送但还没报名的学员后面报了还算我的吗？
15. 合作终止后有没有保护期？（如终止后3个月内，已推学员成交还结算）
