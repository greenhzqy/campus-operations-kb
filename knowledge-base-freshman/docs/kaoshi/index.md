# 期末复习资料

## 这是什么

大一/大二各科目的期末复习资料清单。知道有哪些资料可用，复习的时候就不慌了。

这些资料主要来自历年学长学姐的整理和分享，包括试卷、复习笔记、课后答案。

## 覆盖科目

| 年级 | 科目 |
|------|------|
| 大一上 | 高等数学（上）、C语言程序设计、中国近现代史纲要 |
| 大一下 | 高等数学（下）、线性代数、马克思主义基本原理、微观经济学 |
| 大二上 | 宏观经济学 |

## 怎么用

1. 先看[各科目资料清单](001-各科目资料清单.md)，了解每门课有什么资料
2. 期中/期末考前 2 周开始复习
3. 建议刷一遍历年试卷，熟悉题型和考点

> 📌 资料电子版可以在新生群里问。历年试卷仅作题型参考，不保证每年考的一样。
