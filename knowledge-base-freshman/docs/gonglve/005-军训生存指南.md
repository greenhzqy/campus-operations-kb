# 军训生存指南

## 基本情况

- 时间：开学报到后开始，大约 2 周
- 地点：校内操场/训练场
- 内容：队列训练、军体拳、内务整理、拉歌

## 装备建议

| 物品 | 重要程度 | 说明 |
|------|---------|------|
| 防晒霜 | 🔴 必备 | 重庆 9 月太阳还很猛，男生也别省 |
| 大容量水杯 | 🔴 必备 | 训练间隙补水很重要 |
| 舒适的鞋垫 | 🟡 推荐 | 军训鞋底硬，加个鞋垫舒服很多 |
| 纸巾/湿巾 | 🟡 推荐 | 擦汗用 |
| 创可贴 | 🟢 可选 | 备用 |
| 藿香正气水 | 🟢 可选 | 防中暑 |

## 注意事项

- **身体不适及时报告**：不舒服就举手，不要硬撑
- **多喝水**：少量多次，不要一口气灌
- **按时吃饭**：尤其是早餐，空腹训练容易低血糖
- **晚上早点睡**：军训体力消耗大，别熬夜
- **内务检查**：被子叠好、桌面整洁，检查不过关要扣分

## 可以免训吗？

有医院证明的特殊情况（心脏病、哮喘等）可以申请免训或观训。具体问辅导员。
