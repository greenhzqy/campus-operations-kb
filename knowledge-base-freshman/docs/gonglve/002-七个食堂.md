# 重邮七个食堂怎么选

## 概况

重邮有 7 个食堂（含餐厅），分布在校园不同区域，各有特色。

## 食堂速览

| 食堂 | 招牌 | 推荐指数 |
|------|------|---------|
| 中心食堂 | 三鲜米线（重邮人心中的 yyds）、麻辣香锅 | ⭐⭐⭐⭐⭐ |
| 一食堂 | 小面、盖饭，价格实惠 | ⭐⭐⭐⭐ |
| 二食堂 | 自选快餐，菜品多 | ⭐⭐⭐ |
| 三食堂 | 麻辣烫、冒菜 | ⭐⭐⭐⭐ |
| 四食堂 | 早餐选择多，包子油条豆浆 | ⭐⭐⭐ |
| 五食堂 | 炒菜、干锅 | ⭐⭐⭐ |
| 回民餐厅 | 清真餐，牛肉拉面 | ⭐⭐⭐ |

## 消费参考

- 一顿正餐：10-20 元
- 早餐：3-8 元
- 一个月伙食费大约 800-1200 元（看你怎么吃）

## 小建议

- 新生第一周可以每个食堂都试试，找到自己的口味
- 避开 12:00-12:30 高峰，排队少很多
- 一卡通刷卡消费，也可以微信/支付宝（部分窗口）
- 食堂有微波炉可以热饭
