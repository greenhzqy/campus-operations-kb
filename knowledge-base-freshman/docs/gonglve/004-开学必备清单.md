# 开学必备清单

## 证件类（最重要）

- [ ] 录取通知书
- [ ] 身份证 + 复印件
- [ ] 高考准考证
- [ ] 一寸/二寸证件照（多带几张，电子版也存手机上）
- [ ] 团员证/团组织关系转接证明
- [ ] 银行卡（学校发的和自带的）

## 生活用品类

- [ ] 床上用品：床垫/被子/枕头/床单/枕套（床尺寸 0.9m×1.9m）
- [ ] 洗漱用品：牙刷/牙膏/毛巾/洗发水/沐浴露
- [ ] 拖鞋/衣架/洗衣液
- [ ] 插线板（必带！宿舍插座有限）
- [ ] 小台灯（晚上熄灯后能用）
- [ ] 雨伞（重庆多雨）

## 电子设备类

- [ ] 手机 + 充电器
- [ ] 电脑（不是必须，但大一上有计算机课/写作业用得着）
- [ ] U 盘
- [ ] 耳机

## 不用带的

- ❌ 大功率电器（电饭锅、电磁炉、电热毯——带了会被没收）
- ❌ 太多衣服（宿舍衣柜不大，当季的带够就行）
- ❌ 全套新教材（可以先了解课程再决定买不买，很多可以买二手的）

> 📌 很多生活用品可以在学校超市买，不用大老远背过来。
