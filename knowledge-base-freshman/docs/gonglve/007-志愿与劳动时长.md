# 志愿时长和劳动时长是什么

## 一句话解释

这两个"时长"是大学生的**必修任务**，做不满会影响评优甚至毕业，从大一开始做最轻松。

## 志愿时长

| 项目 | 要求 |
|------|------|
| 每学期 | ≥ 20 小时 |
| 怎么完成 | 参加志愿活动，记录时长 |
| 去哪找活动 | 微信公众号「志愿山城」「志愿计划」 |
| 不达标会怎样 | 影响评优评先资格 |

## 劳动时长

| 项目 | 要求 |
|------|------|
| 毕业总要求 | ≥ 32 学时 |
| 每学期 | ≥ 12 学时 |
| 去哪看 | 企业微信 → 服务大厅 → 劳动教育 |
| 不达标会怎样 | **影响毕业**，大四补做很痛苦 |

## 怎么安排

| 学期 | 建议 |
|------|------|
| 大一上 | 参加 2-3 次志愿活动，适应节奏 |
| 大一下 | 每学期稳定完成，不要拖 |
| 大二-大三 | 保持每学期 12+ 劳动学时 |
| 大四 | 如果还不够，赶紧补 |

## 小提醒

- 返校宣讲（回高中母校）可以认定 2 学时的劳动时长
- 有些活动能同时获得志愿时长和劳动时长，效率高
- 大四才发现不够的同学每年都有，别做那个倒霉蛋
