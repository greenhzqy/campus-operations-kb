# 一分钟逛遍重邮校园

## 校园格局

重邮校园不大但很紧凑，从南到北走路大约 15 分钟。主要分为教学区、生活区和运动区。

## 重要地标

| 地标 | 干什么用的 |
|------|-----------|
| 图书馆 | 自习、借书、查资料（考试周一座难求） |
| 教学楼群 | 上课的地方，按编号找（开学前建议先踩点） |
| 信息中心 | 校园网办理、IT 服务 |
| 学生活动中心 | 社团活动、讲座、演出 |
| 操场/体育馆 | 体育课、体测、日常运动 |
| 校医院 | 看病、体检（入学体检也在这） |
| 快递站 | 取快递、寄快递（开学季排队很长） |

## 小建议

- 报到那天会有志愿者引导，不用担心找不到
- 建议提前一天来踩点，熟悉教学楼位置，开学第一天就不会手忙脚乱
- 图书馆座位紧张，尤其是考试周，想去早点占位
