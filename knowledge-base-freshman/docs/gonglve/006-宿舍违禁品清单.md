# 宿舍违禁品清单

## 绝对禁止

以下物品**带了会被没收**，严重的还会通报批评：

- 🔴 电热毯、电暖器、电热水壶
- 🔴 电饭锅、电磁炉、微波炉
- 🔴 管制刀具、弹弓、仿真枪
- 🔴 麻将（部分楼栋有争议，但最好别带）

## 不建议带

- 🟡 酒类（宿舍不允许存酒）
- 🟡 大功率吹风机（有些楼栋限功率）
- 🟡 面粉、食用油等食材（不能开火做饭，带了也没用）

## 可以用的

- 🟢 笔记本电脑、平板
- 🟢 手机充电器、充电宝
- 🟢 小台灯、小风扇
- 🟢 普通吹风机（功率不超限就行）

> 📌 具体规定以学校最新版学生手册为准。不确定某样东西能不能带？在新生群里问问就行。
