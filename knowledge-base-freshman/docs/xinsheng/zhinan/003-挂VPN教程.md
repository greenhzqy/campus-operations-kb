# 挂 VPN 教程

## 什么时候需要 VPN

- 在校外想上**教务系统**（查成绩、选课）
- 在校外访问**图书馆数据库**（知网、万方）
- 宿舍网络无法直连校内某些系统
- 寒暑假回家需要查成绩

## 怎么装

重邮使用的是 **EasyConnect**（深信服 SSL VPN）：

1. 去学校信息化中心官网下载 EasyConnect
2. 安装后打开，输入服务器地址（下载页面有）
3. 用学号 + 统一身份认证密码登录
4. 连接成功就能访问校内资源了

## 其他校园信息化服务

| 服务 | 干嘛的 | 在哪 |
|------|--------|------|
| 统一身份认证 | 所有系统登录账号 | 学号+密码 |
| 一卡通 | 饭卡充值、消费记录 | 企业微信 |
| 智慧教务 | 选课、查成绩、课表 | 教务处网站 |
| 图书馆系统 | 借书、数据库 | 图书馆网站 |
| 集中收费平台 | 缴学费、住宿费 | 财务处网站 |

> 📌 EasyConnect 版本会更新，去官网下载最新版。遇到连接问题可以在企业微信找信息化中心。
