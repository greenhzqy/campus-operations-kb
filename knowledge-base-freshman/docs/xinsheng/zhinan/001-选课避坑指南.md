# 选课避坑指南

## 选课基本流程

1. 开学后在学校教务系统选课
2. 通识选修课先到先得或抽签
3. 体育课大一必修，大二起可选具体项目
4. 选课时间：开学第 1-2 周

## 选课三大原则

1. **先看老师，再看课程名**：同一门课，不同老师天差地别
2. **看考核方式**：开卷 > 论文 > 闭卷（压力从低到高）
3. **不追热门，追合适**：热门的课不一定适合你

## 通识选修课参考

> 以下来自学长学姐真实评价，仅供参考（老师可能换，课程可能变）

### 👍 口碑较好的课

| 课程 | 亮点 |
|------|------|
| 融合创意与产品运营 | 轻松有趣，容易拿学分 |
| 博弈论 | 期末开卷，容易拿高分 |
| 职场文化 | 老师很好，能学到东西 |
| 项目管理 | 期末交作业，比较轻松 |
| 创业管理 | 老师随和，压力小 |
| 化学与生活 | 非常好混学分 |

### ⚠️ 选之前了解一下

- "期末闭卷"的非专业课 → 性价比低
- "每节课点名"的选修课 → 自由度低
- "小组汇报+论文+考试"三合一 → 一门选修占太多时间
- 评价里出现"给分低""挂过人" → 果断避开

## 体育课选择

- 热门（抢得快）：羽毛球、乒乓球、游泳
- 轻松（好过）：太极拳、健身气功
- 硬核（体测要求高）：田径、足球
