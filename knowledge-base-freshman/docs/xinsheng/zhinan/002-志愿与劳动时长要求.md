# 志愿与劳动时长要求

## 为什么大一就要知道

这两个"时长"是毕业的硬性条件。很多同学大二大三才知道，大四拼命补——提前了解，从大一开始每学期按部就班完成，轻松很多。

## 志愿时长

| 项目 | 要求 |
|------|------|
| 每学期 | ≥ 20 小时 |
| 怎么完成 | 参加志愿活动 → 记录时长 → 学期末汇总 |
| 去哪找 | 微信公众号「志愿山城」「志愿计划」 |
| 不达标 | 影响评优评先资格 |

## 劳动时长

| 项目 | 要求 |
|------|------|
| 毕业总要求 | ≥ 32 学时（本科） |
| 每学期 | ≥ 12 学时 |
| 去哪看 | 企业微信 → 服务大厅 → 劳动教育 |
| 不达标 | **影响毕业**！大四累计不足 36 学时会催补 |

## 高效完成建议

- 部分活动能同时获得志愿时长+劳动时长
- 返校宣讲（回高中）可认定 2 学时劳动时长
- 大一上参加 2-3 次志愿活动就能适应节奏
- 不要拖到大三大四，每年都有补到崩溃的同学

> 📌 具体政策以学校最新通知为准，入学后会发学生手册，里面有详细说明。
