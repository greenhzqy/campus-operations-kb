# 挂VPN教程

## 场景
新生入学后很多校内资源（教务系统、图书馆数据库、选课系统）需要校园网才能访问。在校外或宿舍某些网络环境下，必须挂VPN。几乎每个新生都会遇到"怎么挂VPN"的问题。

---

## 要点

### 什么时候需要VPN？

- 🔍 校外访问**图书馆数据库**（知网、万方等）
- 📋 校外访问**教务系统**（查成绩、选课）
- 📡 宿舍网络无法直连校内某些系统时
- 🏠 寒暑假回家需要查成绩/选课时

### VPN工具：EasyConnect

重邮官方推荐的VPN工具是 **EasyConnect**（深信服SSL VPN客户端）。

**安装步骤**：
1. 下载EasyConnect客户端（学校信息化中心官网有下载链接）
2. 安装后打开，输入服务器地址（详见学校VPN指南PDF）
3. 用学号和统一身份认证密码登录
4. 连接成功后即可访问校内资源

### 其他校内信息化服务

| 服务 | 用途 | 入口 |
|------|------|------|
| 统一身份认证 | 所有系统的登录账号 | 学号+密码 |
| 一卡通服务 | 饭卡充值、消费记录 | 企业微信/财务处 |
| 智慧学工系统 | 评优评先、勤工助学 | 学生处 |
| 智慧教务 | 选课、查成绩、课表 | 教务处 |
| 图书馆系统 | 借书、数据库访问 | 图书馆 |
| 集中收费平台 | 缴学费、住宿费 | 财务处 |
