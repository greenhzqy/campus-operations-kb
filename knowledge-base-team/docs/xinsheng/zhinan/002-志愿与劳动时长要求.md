# 志愿与劳动时长要求

## 场景
新生入学后经常问"志愿时长是什么？""劳动时长不够能毕业吗？"——这些是硬性毕业要求，但很多新生到大二大三才知道，提前了解的学长就显得特别靠谱。

---

## 要点

### 志愿时长

| 维度 | 要求 |
|------|------|
| 每学期要求 | ≥ 20小时/学期 |
| 认定方式 | 志愿活动项目+时长认定 |
| 查看途径 | 微信公众号「志愿山城」/「志愿计划」 |
| 参考文件 | 《学生手册》156~160页 |
| 是否硬性 | **是硬性要求**，不达标影响评优评先 |

**怎么完成**：
- 关注微信公众号"志愿山城"或"志愿计划"
- 扫描二维码查看适合自己的志愿项目
- 参加活动 → 记录时长 → 学期末汇总
- 部分活动还可同时获得劳动时长

### 劳动时长

| 维度 | 要求 |
|------|------|
| 毕业总要求 | ≥ 32学时（本科） |
| 每学期要求 | ≥ 12学时/学期（大一到大三） |
| 认定方式 | 学校劳动教育系统 |
| 查看途径 | 企业微信 → 服务大厅 → 劳动教育 |
| 是否硬性 | **是硬性毕业条件**，不达标无法毕业 |
| 特殊说明 | 返校宣讲可认定2H（不重复计算） |

**重要提示**：
- 劳动教育考核纳入综合素质测评体系
- 不达标 → 取消评优评先资格
- 大四时累计不足36学时 → 学院会督促补做
- **地方母校宣讲**可认定2学时（但不可累积）

---

## 禁忌
- 不要建议学生"刷时长"或弄虚作假
- 具体政策每年可能有微调，提醒新生以最新通知为准
- 不要在公开平台批评学校的时长制度
