# 私信问有没有某本书

## 场景
用户在私信中询问"有没有XX教材"，需要快速响应并促成交易。

## 话术 / 要点
"有的！《高等数学》同济第七版，书况良好，有一些铅笔笔记但不影响使用。我拍个照片给你看看 👇 **【发照片】**

原价45，二手25出。还有配套的习题解答，要的话一起40给你。你在重邮的话可以当面给你，省个邮费～"

### 核心流程
1. 确认有书
2. 拍照发图（书况如实展示）
3. 报价
4. 确认交付方式（自取/快递）
5. 促成交

## 禁忌
- 不要夸大书况，必须如实描述笔记程度和破损情况
- 不确定版本时让对方先跟老师确认
