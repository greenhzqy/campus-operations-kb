# 库存管理方法

## 场景
管理二手书库存，避免积压和亏损，保持高周转率。

## 要点

### 管理四原则
- **不囤积**：每门课最多存5本，超出的不收
- **快周转**：开学2周内出清，卖不掉的不再进货
- **淘汰机制**：一学期卖不掉的书 → 下学期降价到成本价出清或送给学弟学妹做人情
- **照片存档**：每本书拍照留档，避免书况争议

## 禁忌
- 不要囤积冷门专业课教材（周转慢、风险高）
- 不要超过每门课5本的上限
- 不要省略拍照存档环节（售后争议无凭据）
