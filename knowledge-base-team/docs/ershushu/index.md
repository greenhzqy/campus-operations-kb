# 二手书业务知识库

## 业务概述

二手书是面向重邮新生的第三业务线，与驾校、校园卡形成"通信→学习→技能"的全场景覆盖。核心逻辑：从高年级收旧书，开学季卖给新生，帮助新生省钱的同时建立信任。

- **定位**：大学教材、教辅、考证资料（二手）+ 期末复习资料
- **目标用户**：大一新生为主（必修课教材），大二/大三为辅（专业课+考证）
- **核心窗口**：卖书（9月/2月开学），收书（1月/6月期末）
- **定价策略**：教材新书价30%-50%，复习资料单科5-15元
- **红线**：不坐班、不处理纠纷、不碰钱（尽量）

> 💡 **复习资料**是二手书业务的自然延伸。详见 [复习资料板块](../fuxiziliao/index.md)。
