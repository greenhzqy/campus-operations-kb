- **运营节奏**：年度时间线（卖书黄金期9月/2月，收书黄金期1月/6月）

### 📖 复习资料

大学课程期末复习资料（试卷+笔记+题库），二手书业务自然延伸，考前刚需。

- **覆盖科目**：高数、C语言、线代、近现代史、马原、微观经济学等
- **核心策略**：考前2周冲刺销售 + 与二手书捆绑，电子版零成本走量
- **定价**：单科5-15元，打包30-50元
