# 校园卡业务知识库

## 业务概述

- **身份**：重邮在读学长，抖音博主（重邮新生干货）
- **产品**：中国移动校园卡（主推 59元/月）+ 中国电信校园卡（备选 29元/月）
- **目标用户**：重邮新生为主，大二/大三未办校园卡的学生为辅
- **核心窗口**：7-8月暑假迎新季（黄金期）
- **销售形式**：纯线上：抖音/小红书/新生群引流 → 点对点沟通 → 推送办卡链接/二维码 → 运营商发货
- **红线**：不坐班、不售后、不处理纠纷
