# 对方还没确定学校时的保温话术

## 场景
新生表示还在等录取结果、学校还没确定，暂时无法办卡。需要保温维护关系，避免流失。

## 话术 / 要点

> 先恭喜你！等录取结果出了第一时间告诉我学校和专业，我帮你看看有什么要注意的～

> 校园卡的事不急，你先安心等结果。拿到录取通知书之后随时找我，暑期优惠持续到开学前 ✌️

### 保温要点
- **先恭喜和祝福**，把好消息放在前面
- **主动提供后续价值**："帮你看看有什么要注意的"（专业/学校建议）
- **明确告知优惠时效**：暑期优惠持续到开学前，让对方放心
- **不施加压力**：让节奏由对方掌控

## 禁忌
- 不要在对方等结果焦虑时施压办卡
- 不要说"越早办越好"等催促话术
- 不要在对方明确说等通知后还反复追问
- 不要擅自替对方判断"你大概率上哪个学校"
