# 选题：学车怎么选

## 时间
7月下旬或8月中旬（在发了5-8条泛吸引内容后）

## 视频结构
60-90秒
- 开头引出话题（10秒）："最近好多学弟学妹私信问学车的事，干脆出一条视频说一下。"
- 讲经验（20秒）："学校周边有好几家驾校，有的报价便宜但后期加钱，有的教练态度差。很多同学反馈九城的整体体验还行。"
- 选驾校关键点（30秒）：
  1. 看合同是不是一费到底（别贪便宜）
  2. 看场地离学校多远（练车方便很重要）
  3. 看教练态度（能不能换教练）
  4. 看通过率（驾校都会说高，自己去问学长学姐）
- 结尾CTA（10秒）："有想了解的可以私信我们，把合作驾校的负责人微信推你，你自己去问，多对比一下没毛病。"

## 植入方式
**唯一一条明确推驾校的视频**，全程不说价格数字、不说"必选XX驾校"、不踩其他驾校名字。最多出1-2条，不超过总内容的5%。

## 为什么有效
用真实经历+实用选校指南建立信任，CTA自然引导私信
