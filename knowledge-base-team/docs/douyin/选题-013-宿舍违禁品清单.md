# 选题：宿舍违禁品清单！带了会被没收的

## 时间
7月底-8月中（新生准备行李前）

## 视频结构
40-50秒
- 开头（3秒）："开学千万别带这些东西进宿舍，会被没收的！"
- 中间：逐项列出宿舍禁止的电器和物品
  - 电热毯、电暖器、电饭锅、电磁炉
  - 管制刀具、弹弓、玩具枪
  - 麻将、扑克（部分楼栋有争议）
  - 酒、食用油、面粉等（不能开火的食材）
- 结尾："带什么看开学清单那期视频，链接在评论区 👇"

## 植入方式
不植入，纯干货。结尾引导看「开学必备清单」那期（可以在清单里植入二手书/校园卡）。

## 为什么有效
- 新生怕犯错，这类"避坑"信息天然高收藏
- 每个大学都有类似规定，搜索流量大
- 信息来源：官方宿舍电器违规认定文件

## 信息来源
- 重邮宿舍电器违规情况认定文件
- 官方学生手册相关条款
