# 选题：大一最该做的5件事

## 时间
7月下旬

## 视频结构
50-60秒
- 第1件：熟悉校园，交几个靠谱朋友
- 第2件：把GPA稳住，大一上别挂科
- 第3件：加1-2个社团，别太多
- **第4件（植入位）**：趁大一课少把驾照考了，能加素质学分。后面大二大三忙起来真没时间。周围大一就拿证的同学都挺庆幸的
- 第5件：多拍照记录，四年很快

## 植入方式
5件事里只有1件是学车，比例自然，不突兀

## 为什么有效
"该做的事"= 新生有决策需求 = 你帮他们做了规划 = 信任
