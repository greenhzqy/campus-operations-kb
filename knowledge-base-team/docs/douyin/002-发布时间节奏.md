# 发布时间节奏

## 场景
按时间阶段规划抖音内容的发布节奏，确保每个阶段目标明确。

## 要点

### Phase 1：抢跑期（6月下旬-7月上旬）—— 占坑
| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第1周 | 宿舍长啥样 + 7个食堂 | 第一批搜索流量，测内容方向 |
| 第2周 | 逛校园 + 社团推荐 | 持续涨粉，建立校园账号认知 |

**这个阶段不发任何植入。** 新生刚高考完，还没录取。

### Phase 2：信任建设期（7月中旬-8月中旬）—— 种草
| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第3周 | 开学必备清单 + 大一最该做的5件事 | 清单引导私信，首次软提学车 |
| 第4周 | 一个月开销 + 逛校园精简版 | 开销视频首次提学车预算 |
| 第5周 | 学车怎么选（促转化）+ 周边好玩 | 唯一主推驾校视频，配纯娱乐稀释 |
| 第6周 | 开学第一个月待办 + 军训指南 | 再软提学车，军训缓解焦虑 |

**关键节奏**：每2-3条纯干货后夹1条软种草。促转化视频放在有粉丝基础之后。

### Phase 3：转化冲刺期（8月下旬-9月中旬）—— 收割
| 时间 | 发布内容 | 目的 |
|------|---------|------|
| 第7周 | 选课避坑 + 图书馆指南 | 纯干货维持热度 |
| 第8周 | 大一最没必要做的事 | 首次植入二手书 |
| 第9周 | 值得考的证 | 自然植入驾照 |
| 第10周 | 大一上学期时间线 | 纯干货维持涨粉 |

**重点不在视频推，而在私信转化。**

### Phase 4：稳定维护期（9月下旬-10月）
- 维持每周1-2条纯干货
- 不再出新促转化内容
- 偶尔软植入（二手书）
- 重心转移到私信回复和推代理微信

## 禁忌
- 不要在抢跑期发任何植入内容
- 不要在冲刺期过度发促转化内容
- 不要跳过抢跑期直接进入种草期
