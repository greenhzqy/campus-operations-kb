# 担心隐形消费、教练态度、练车距离

## 场景
新生表达顾虑：「怕被坑」「听说驾校教练骂人」「会不会后期乱收费」「练车地方远不远」。

## 话术

> 说实话很多同学报之前也担心这些😂 有同学在家学车被教练骂惨了，所以选驾校的时候特意考察了九城，他们教练有淘汰制，态度差的会被换掉。费用的话合同里写清楚一费到底，后期不收杂七杂八的。
>
> 不过具体你可以直接问他们负责人确认，合同条款也让他发你看看。👉 [推送代理微信]
>
> 反正你问清楚再决定，不着急，别被忽悠了就行。

## 要点
- 共情 + 分享实际案例（建立信任）
- 把最终确认责任推回代理方
- 不替驾校做担保，让学员自己跟代理确认

## 禁忌
- 不说「绝对没问题」「包你满意」这类绝对担保
- 不转述代理的任何口头承诺
- 不说其他驾校的负面信息
