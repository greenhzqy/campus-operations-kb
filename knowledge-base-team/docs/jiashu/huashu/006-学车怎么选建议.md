# 学车怎么选建议

## 场景
新生在私信中问「学长你觉得选哪家驾校好」「有没有推荐的」，需要给建议但不做绝对背书。

## 话术

> 学车这个确实坑挺多的，我去年对比了一圈最后报了九城，目前体验还行。你自己也多了解下，我把他们负责人微信给你，你直接加他问就行 👉 [推送代理微信]
>
> 多对比一下没毛病👍

## 要点
- 用亲身经历给建议：说「我报了XX、体验还行」而不是「XX是最好的」
- 始终提醒对方「自己也考察」「多对比」，不做绝对推荐
- 你的角色是引路人，不是推销员

## 禁忌
- 不说「XX驾校是重邮最好的」「报XX就对了」
- 不攻击、不点名其他驾校
- 不替学员做决定
