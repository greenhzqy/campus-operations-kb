# 点对点聊天四步法

## 场景
私信沟通中与新生建立信任关系的方法论，核心是「先帮人、再谈事」，不要一上来就暴露「我是推驾校的」。

## 要点

### 第1步：先解答疑问
对方问什么就先答什么——宿舍怎么样？食堂好吃吗？专业怎么选？选课有什么坑？
**不要跳过问题直接推销。**

> 驾校场景：新生问的是开学、选课、宿舍——就答这些，别提学车

### 第2步：给实用建议
结合对方的专业或地区，给1-2条开学/大学生活的小建议。让对方觉得你真的在帮他，不是机器人客服。

> 「对了，大一课少，很多同学会趁这学期把驾照考了，后面大二大三忙起来就没时间了」

### 第3步：带出学车场景
自然过渡：课余时间怎么利用？加素质学分有什么途径？——引出学车这件事，但不直接推驾校。

> 「大学课余时间挺多的，好多同学大一就把驾照拿了，还能加素质学分。你是打算在校学还是回家学？」

### 第4步：自然切入，推微信
对方表现出兴趣后 → 分享自己的学车经历 → 推荐咨询渠道 → 推送代理微信。

> 「团队合作了九城，目前体验还不错。你要了解的话我把他们负责人微信给你，你自己问，比我在中间传话靠谱。多对比一下没毛病👍」

## 关键原则
不要一上来就暴露「我是推驾校的」。先帮对方解决实际问题，建立信任后再自然过渡。你是**内容引流被动获客**，不是主动推销。
