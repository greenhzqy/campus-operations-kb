# 业务冲突风险

## 场景
与代理方在边界问题上可能产生的4种业务冲突——代理施压推校园卡、要求建团队、要求线下站台、其他驾校找来。

## 风险及规避方法

| 风险 | 规避方法 |
|------|---------|
| 代理施压通过他们渠道推校园卡 | 明确「校园卡有独立合作渠道，不通过驾校代理方做」，写进协议 |
| 代理要求建团队 | 团队规模由内部决定，不接受代理方要求扩张 |
| 代理要求线下站台 | 协议写死「仅线上引流」，线下要求一律否决 |
| 其他驾校也来合作 | 可多家合作但保持透明；同一学员不同时推多家 |

## 禁忌
- 不接受任何线下要求
- 不接受建团队、带人的要求
- 不把校园卡业务混入驾校合作
