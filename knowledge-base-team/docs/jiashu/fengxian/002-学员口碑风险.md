# 学员口碑风险

## 场景
驾校服务质量影响团队口碑——服务差、代理乱承诺、学员公开投诉，三种核心风险。

## 风险及规避方法

| 风险 | 规避方法 |
|------|---------|
| 驾校服务差 → 学员投诉推荐人 | 话术永远说「体验因人而异，你自己也要考察」，不给绝对背书 |
| 代理乱承诺 → 学员找推荐人对质 | 绝不转述代理的任何承诺，把责任推回代理方 |
| 评论区公开投诉 | 公开回「私你了」，私下按场景5处理，不公开撕 |

## 禁忌
- 不说「绝对靠谱」「包你满意」
- 不替代理做承诺
- 不公开吵架
