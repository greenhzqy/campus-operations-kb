# 结算风险

## 场景
与代理方结算提成时可能遇到的4种核心风险。

## 风险及规避方法

| 风险 | 规避方法 |
|------|---------|
| 代理不认账「这学员是我们招的」 | 每次推送保留截图+时间戳，对账当凭证 |
| 学员只交定金，提成悬空 | 协议写明「全款到账才算」，定金不提成 |
| 代理拖欠、耍赖 | 固定每月5号结算，超期暂停推送新学员 |
| 单子少不单独结算 | 协议写死「不论单量，有就结」 |

## 禁忌
- 不要凭口头约定结算——必须有截图凭证
- 不要接受「月底一起算」「有空再结」等模糊说法
