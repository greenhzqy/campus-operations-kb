# 合规红线7条

## 场景
任何时候都必须遵守的7条合规底线，踩任何一条都可能出大问题。

## 7条铁律

1. **不虚假宣传**：价格、通过率、拿证时间等以驾校官方公示为准，不说「包过」「必过」

2. **不诋毁友商**：用事实和自身体验说话，不攻击、不点名、不传播其他驾校负面信息

3. **不攻击家长**：家长有顾虑很正常，建议沟通，不煽动对立

4. **不制造焦虑**：不用「不报就涨价」「改革变难」「不学就吃亏」等恐吓式话术

5. **保护个人信息**：不随意收集、传播学员个人信息，推送代理微信前征得对方同意

6. **合规添加好友**：不频繁骚扰、不刷屏、不复制粘贴同一条评论，遵守平台规则

7. **不碰钱不碰合同**：任何费用由驾校直接收取，合同由驾校与学员直接签署

## 禁忌
- 代理手册中的「威逼利诱」（用改革难度翻倍吓学员）踩线了，必须弱化为客观提醒
