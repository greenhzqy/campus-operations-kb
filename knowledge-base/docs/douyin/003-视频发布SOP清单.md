# 视频发布SOP清单

## 场景
每条视频发布前的标准检查流程，以及发布后的评论区运营要点。

## 要点

### 发布前检查清单
- [ ] **标题关键词**：是否包含「重邮」「新生」「大一」「宿舍」「食堂」等？
- [ ] **封面大字标题**：新生刷到一眼能看懂是什么内容？
- [ ] **引导互动**：有没有评论区提问 / 引导私信 / 引导点赞？
- [ ] **话题标签**：有没有加 #重邮 #重庆邮电大学 #大一新生 #开学准备？
- [ ] **植入比例**：泛吸引期=0植入 / 种草期=1句 / 促转化=整条但不超过总量5%？
- [ ] **语气检查**：是不是学长的口语？有没有营销味？
- [ ] **合规红线**：不制造焦虑 / 不虚报数字 / 不踩其他驾校？

### 评论区运营要点
- 发布后24小时内：回复所有评论（前期人少，全回）
- 有人问学车 → 评论回复"私你了兄弟"，转私信按话术处理
- 有人质疑驾校 → 不公开争吵，私信解释
- 有人问其他问题 → 认真回复，体现"真学长"人设
- 有人问二手书 → 回复"私信我帮你找"

## 禁忌
- 不要在评论区公开争吵（尤其是驾校相关质疑）
- 不要漏加话题标签
- 不要忽视发布后24小时内的评论回复
