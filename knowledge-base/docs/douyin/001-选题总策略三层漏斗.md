# 选题总策略：三层漏斗

## 场景
理解抖音账号内容规划的核心策略，确保内容比例合理，避免账号变味。

## 要点

### 三层漏斗结构

**第一层：泛吸引（70%）**
- 重邮校园干货，无植入，纯涨粉
- 目的：让新生关注你、信任你
- 选题类型：宿舍、食堂、校园环境、开学清单、选课、军训、社团等

**第二层：软种草（25%）**
- 开学准备/大学生活规划，顺带提学车/二手书
- 目的：埋下需求种子，让新生主动私信
- 选题类型：大一最该做的事、最值得考的证、月开销、最没必要做的事

**第三层：促转化（5%）**
- 学车避坑/经验分享，引导私信，推代理微信
- 目的：成交
- 严格控制数量，一条就够了，多了号就废了

### 核心逻辑
90%的人刷到你是因为想看新生攻略，不是想报驾校。先用干货把人留住，再用软植入筛选意向，最后私信转化。

## 禁忌
- 不要一上来就推驾校，号会废
- 三层的 70-25-5 比例不能打破
- 促转化内容最多占总量 5%
