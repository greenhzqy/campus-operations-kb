# 选题：大一不搞这个，大四毕不了业

## 时间
8月中-9月初（入学后尽快发）

## 视频结构
45-60秒
- 开头（3秒）："你知道志愿时长和劳动时长吗？不知道的话这期一定要看完。"
- 中间：
  - 志愿时长：每学期≥20小时，不达标影响评优
  - 劳动时长：本科毕业要≥32学时，每学期≥12学时
  - 怎么看：微信公众号"志愿山城" + 企业微信服务大厅
  - "大四才补的话学院会催你，心态会崩的"
- 结尾："从大一开始，每学期保证做完，大四就不用慌了。"

## 植入方式
不植入。结尾说"更多新生避坑指南，关注我，下期讲选课。"

## 为什么有效
- "毕不了业"是强钩子，焦虑驱动点击
- 几乎所有新生都不知道这两个时长要求
- 收藏率高（实用信息），转发给同学的概率大

## 信息来源
- 志愿时长与劳动时长官方文件
- 重邮学生手册相关条款
