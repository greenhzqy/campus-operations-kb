# 抖音选题知识库

## 三层漏斗概述

```
第一层：泛吸引（70%）—— 重邮校园干货，无植入，纯涨粉
第二层：软种草（25%）—— 开学准备/大学生活规划，顺带提学车/二手书
第三层：促转化（5%）——  学车避坑/经验分享，引导私信，推代理微信
```

核心逻辑：90%的人刷到你是因为想看新生攻略，不是想报驾校。先用干货把人留住，再用软植入筛选意向，最后私信转化。
