# 关键数据指标

## 场景
判断抖音内容方向是否正确，根据数据指标决定是否需要调整策略。

## 要点

| 指标 | 正常范围 | 需调整 |
|------|---------|--------|
| 泛吸引内容播放量 | 高于粉丝数3-5倍 | 低于粉丝数 = 选题或标题有问题 |
| 泛吸引内容互动率 | 5%-10%（赞+评+收藏） | 低于3% = 内容不够有用或不够有趣 |
| 软种草内容互动率 | 3%-5% | 低于2% = 植入太生硬，调整话术 |
| 促转化内容评论数 | 至少有3-5条咨询学车 | 0咨询 = 信任没建立够，先回去发泛吸引内容 |
| 私信转化率 | 每100个私信咨询→推代理微信→5-10人最终报名 | 低于3% = 私信话术需优化或推送时机不对 |

### 调整建议
- 播放量低 → 检查标题和封面是否吸引人
- 互动率低 → 内容不够有用，增加干货密度
- 促转化无咨询 → 回到泛吸引内容，继续建立信任
- 私信转化低 → 优化话术或调整推送时机

## 禁忌
- 不要只看播放量，互动率和转化率才是核心
- 不要在数据不好时立即换方向，先分析原因
