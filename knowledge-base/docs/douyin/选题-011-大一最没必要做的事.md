# 选题：大一最没必要做的事

## 时间
10月上旬

## 视频结构
40-50秒
- 不用急着谈恋爱（顺其自然）
- 不用加太多社团（1-2个够了）
- 不用卷所有课（重点课把握好）
- 不用买太多新书（可以找学长学姐买二手的）
- **二手书植入位**："很多教材买新的太贵了，找学长学姐买二手的能省一半，书况还很好"

## 植入方式
在"最没必要做的事"中带出二手书，是省钱建议而非推销

## 为什么有效
"没必要做的事"=反焦虑=高好感度，"二手书"在这里不是生意=是省钱建议
