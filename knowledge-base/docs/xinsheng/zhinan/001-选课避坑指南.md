# 选课避坑指南

## 场景
新生入学后第一件事就是选课。哪些老师好过？哪些课是坑？一份靠谱的选课参考能帮新生少走弯路——这也是非常好的抖音选题素材。

---

## 要点

### 选课基本流程（重邮）

1. **通识选修课**：开学后在学校教务系统选，先到先得或抽签
2. **体育课**：大一有体育必修，大二起可以选具体项目
3. **选课时间**：开学第1-2周为选课周，具体看教务处通知

### 选课三大原则

1. **先看老师，再看课程名**：同一个课程，不同老师差别巨大
2. **看考核方式**：开卷/闭卷/论文/作业，直接决定你的期末压力
3. **不追热门，追合适**：热门的课不一定适合你，冷门的可能给分更高

## 热门通识选修课参考

> 以下信息来自学长学姐真实评价汇总，仅供参考（老师可能换，课程可能变）

### 👍 推荐类（好评较多）

| 课程 | 老师推荐 | 亮点 |
|------|---------|------|
| 融合创意与产品运营 | 刘绍平/刘璐/张祖成 | 学分的课，轻松且有趣 |
| 博弈论 | 李伟 | 期末开卷考试，容易拿高分 |
| 职场文化 | 徐强 | 老师很好，能学到东西 |
| 项目管理 | 何建洪/文静 | 期末交作业，比较轻松 |
| 创业管理 | 刘虹 | 老师随和，压力小 |
| 化学与生活 | 赖文勇 | 非常好混学分 |

### ⚠️ 慎重选择类（争议较大）

| 课程 | 原因 |
|------|------|
| 逻辑学（畅雅雯） | 上课体验一般，给分不高 |
| 知识产权法（某老师） | 期末闭卷考试，难度大 |
| 某些"水课" | 虽然轻松但老师点名频繁，反而折腾 |

### 🔴 避坑信号

- "期末闭卷" → 对于非专业课，闭卷=性价比低
- "每节课点名" → 如果是选修课且你说不上很喜欢，建议退
- "小组汇报+论文+考试三合一" → 一门选修课占太多时间不值得
- 评价中出现"给分低"、"挂过人" → 果断避开

## 体育课选择

> 大一体育为必修通选，大二起可选具体项目

- **热门项目**：羽毛球、乒乓球、游泳（抢得快）
- **轻松项目**：太极拳、健身气功（好过）
- **硬核项目**：田径、足球（体测要求高）
- **体测说明**：每学期有体测（800m/1000m、引体向上/仰卧起坐等），详见体育课细则

## 禁忌
- 不要公开点名批评某位老师（容易惹麻烦），用"据说""有同学反馈"
- 选课评价具有时效性，每年可能换老师，提醒新生自行核实
- 不要在官方群或学校平台发布选课红黑榜
