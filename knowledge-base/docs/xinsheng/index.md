# 新生指南知识库

## 业务概述

新生指南是抖音内容的**干货弹药库**——用真实有用的入学信息吸引新生关注，建立"重邮学长"的专业人设。这里的每一条信息都可以变成一条短视频或一篇小红书笔记。

- **定位**：重邮新生入学必备信息汇总（官方资料+学长经验）
- **目标用户**：拿到录取通知的大一新生（7-9月）及其家长
- **内容用途**：抖音/小红书选题素材、新生群答疑素材、私信破冰素材
- **信息来源**：学校官方培训PPT/PDF + 学长学姐实际经验 + 选课评价

## 核心新生时间线

| 时间 | 新生状态 | 需要什么信息 | 适合推什么 |
|------|---------|------------|-----------|
| 7月中-8月初 | 拿到录取通知 | 学校什么样？宿舍好不好？ | 泛吸引内容（校园/宿舍/食堂） |
| 8月中-8月底 | 准备入学 | 带什么？办什么卡？ | 开学清单 + 校园卡 |
| 9月初 | 报到入学 | 选课怎么选？怎么上网？ | 选课指南 + VPN教程 |
| 9月中-10月 | 正式上课 | 社团活动？志愿时长？ | 软种草内容 + 驾校 |
| 11-12月 | 适应大学生活 | 期中期末怎么复习？ | 复习资料 + 驾校 |
