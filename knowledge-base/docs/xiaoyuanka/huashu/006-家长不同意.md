# 应对家长不同意办卡

## 场景
新生想办校园卡，但家长担心乱收费、不正规、怕被骗，不同意孩子办理。

## 话术 / 要点

> 理解理解，家长担心乱收费很正常～校园卡其实是免费领取的，暑假还免费用。你可以跟爸妈说这个套餐是学校官方合作的，正规渠道办的，售后有保障。

> 不急，你慢慢跟家里沟通～反正随时可以找我办。

### 应对要点
- 先**共情**：承认家长的担心是正常的，不否定
- 强调**免费领取**和**暑假免费用**，降低经济顾虑
- 强调**学校官方合作**和**正规渠道**，建立信任
- 不给压力：让对方慢慢沟通，不催

## 禁忌
- **不攻击家长**："你爸妈怎么这样""太保守了"等说法绝对禁止
- **不煽动对立**：不在新生和家长之间制造矛盾
- 不虚假承诺"绝对没有任何费用"
- 不催促"趁你爸妈不在偷偷办"
