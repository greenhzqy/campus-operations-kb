# 从答疑自然过渡到校园卡

## 场景
在与新生的日常答疑中（聊完宿舍/食堂/选课后），自然地将话题过渡到校园卡，避免生硬切换。

## 话术 / 要点

### 四步法中的关键过渡（第3步：带出用网场景）

自然引入用网刚需场景：选课抢课、查成绩、刷慕课、资料下载 → 流量和网络稳定很重要 → 引出校园卡话题。

> 对了跟你说个事～开学抢课对网速要求挺高的，重邮教务系统你是知道的😅 我们那届好多同学在宿舍用手机热点抢课，结果页面都刷不出来…

> 对了，开学抢课要拼手速+网速，学校的教务系统大家都懂的…校园网稳一点会方便很多。你了解过校园卡吗？

### 对方有兴趣后切入

> 校园卡是免费领取的，迎新季专门给学生准备的套餐，流量和通话时长都比较适合学生用。移动这个59的套餐暑假免费用两个月，你可以提前了解一下，开学直接用～

## 禁忌
- 不要在对方还没聊完自己关心的问题时就强行切换话题
- 不要跳过答疑直接推销校园卡
- 不要用恐吓式话术（"不办卡就抢不到课"）
