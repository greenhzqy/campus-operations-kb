# 群内自然植入校园卡话题

## 场景
在新生答疑群里回答选课/宿舍/网络相关问题时，自然地植入校园卡话题，不让人觉得是广告。

## 话术 / 要点

> 选课的话建议用校园网，比较稳。宿舍宽带要办了校园卡才能用。你们拿到录取通知书之后就可以提前办了，开学直接激活就行，不用去营业厅排队～

### 植入要点
- 以**回答具体问题**为切入（选课、宽带等），不凭空冒出一句广告
- 把校园卡包装成**解决方案的一部分**，而非推销产品
- 强调"不用去营业厅排队"这个实际痛点
- 语气自然、信息密度适中，不像复制粘贴

## 禁忌
- 不要在群里直接发广告
- 不要@所有人 推销
- 不要在无人询问时突兀植入
- 不要大段复制粘贴套餐文案
