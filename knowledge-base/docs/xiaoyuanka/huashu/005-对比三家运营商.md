# 对比三家运营商话术

## 场景
新生询问移动、联通、电信校园卡的区别，需要客观对比并引导到移动。

## 话术 / 要点

> 三家各有特点，主要看你看重什么。移动是学校官方独家合作的，信号最稳定，校内团队上门服务也方便。学校大部分人都选的移动，你可以问问身边学长学姐实际使用感受～

### 关键对比维度（移动优势）

| 对比维度 | 移动优势 |
|---------|---------|
| 基站 | 独立基站（非共享），网速更快 |
| 校园地位 | 学校官方独家合作 |
| 覆盖率 | 约70%学生使用 |
| 售后 | 校内团队上门服务 + 专属售后群 |
| 月租 | 59元/月，7-8月免费 |

### 双卡策略
主推移动（校内团队+独立基站+售后优势明显），电信（29元/月）作为预算敏感型新生的备选。两家可同时做，同一新生只推一家。

## 禁忌
- **不要诋毁友商**："联通信号很差""电信不行"等说法绝对禁止
- 用"XX也不错"而不是"XX不行"
- 不制造虚假对比信息（如编造友商负面数据）
- 不攻击家长或对方已办的其他运营商卡
