# 销售全流程（5步）

## 场景
全面掌握校园卡从引流到结算的完整销售路径，适用于新人上手培训。

## 要点

```
建群/引流 → 群内答疑 → 私聊切入 → 推办卡链接 → 记账对账
```

### 1. 建群/引流
抖音/小红书发新生干货 → 评论区互动 → 拉新生群

### 2. 群内答疑
群内回答新生问题（宿舍/食堂/选课），建立信任

### 3. 私聊切入
自然过渡到校园卡话题，四步法建立信任

### 4. 推办卡链接
发办理二维码/链接，协助完成下单

### 5. 记账对账
记录日期+昵称+手机号+激活状态，月结对账

## 禁忌
- 不在群里直接发广告
- 不跳过答疑直接推销
- 不遗漏记账（否则结款无凭证）
