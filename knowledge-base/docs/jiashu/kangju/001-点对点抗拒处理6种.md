# 点对点抗拒处理（6种）

## 场景
私信沟通中遇到新生各种抗拒时的完整应对思路。

## 应对思路表

| 抗拒 | 应对思路 |
|------|---------|
| 「这驾校没听过/不靠谱吧」 | 我自己对比了好几家最后选了九城，目前体验下来还可以。你也可以问问身边报了驾校的同学实际感受，兼听则明～ |
| 「我再考虑一下/不急」 | 当然可以，决定权在你。只是大一课少、时间多，是学车的黄金期。到了大二大三忙起来真不好挤出时间。你慢慢考虑，有疑问随时问～ |
| 「不知道选哪家驾校好」 | 各有特点，主要看你看重什么。如果看重费用透明、教练态度、练车方便，我报的九城性价比还不错。你可以几家都问问对比一下。 |
| 「我等开学再说」 | 开学也行，但开学季报名的人多，教练排期会比较紧。现在提前了解清楚，开学直接办，能省不少排队时间。 |
| 「你是不是推销驾校的？」 | 哈哈我主要是给新生答疑的，学车只是我觉得确实有用才提一嘴。报不报都随你，交个朋友也行～ |
| 「我爸妈让我回家学/我不需要」 | 理解～很多同学一开始也这么想的。但家里寒暑假是旺季，排队久、天气差，万一挂科要拖到下一个假期。你可以先了解一下在校学的方案，对比一下不亏。 |

## 核心禁忌
- 不制造焦虑：不说「不报就涨价」「改革变难」「不学就吃亏」
- 不诋毁其他驾校
- 不攻击家长
- 不虚假宣传
- 代理手册里的「威逼利诱」踩线了，弱化为客观提醒
