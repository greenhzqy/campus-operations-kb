# 极简引流四步法

## 场景
从0到1的完整线上引流操作流程，是驾校代理业务的核心骨架。

## 全流程

```
发内容 → 回私信 → 推微信 → 记账
（4步走完，无第5步）
```

## 每一步详解

**第1步：发内容（日常持续）**
- 抖音发布重邮新生干货视频（校园攻略、避坑指南、开学清单等）
- 视频中软植入驾校/二手书信息（如拍操场时顺带「练车场地就在附近」）
- 主页简介可写「学车/二手书私信学长帮你避坑」
- 不做硬广视频，不单独为驾校出一条推销视频
- 驾校相关内容不超过总内容的10%

**第2步：回私信（不超过5轮）**
- 评论区有人问学车 → 回复「私你了兄弟」
- 转私信后简短沟通，判断基本意向
- 口语化学长风格回复，带表情符号
- 核心目标：判断对方是否有真实意向

**第3步：推微信（一次搭桥）**
- 确认对方有意向 → 直接发代理微信名片/微信号
- 话术：「这是我报的那家驾校的负责人，你直接加他问就行，比我说得清楚」
- 推送后你的操作即结束，不再主动跟进

**第4步：记账（月底对账用）**
- 简单记录：日期 + 学员微信昵称 + 推送给了哪个代理
- 用途：月底对账时核对成交
- 不做CRM、不做跟进表、不做学员档案

## 禁忌
- 不问学员「报名了吗」「考虑得怎么样」
- 不建学员群、不维护学员关系
- 不处理任何投诉和纠纷
- 不碰钱、不碰合同
