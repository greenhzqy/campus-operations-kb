# 账号人设风险

## 场景
做驾校代理对抖音「重邮学长」人设的潜在伤害——变成推销号、商业化太重、合作到期后绑定。

## 风险及规避方法

| 风险 | 规避方法 |
|------|---------|
| 变成驾校推销号 → 掉粉 | 驾校内容 ≤ 10%，主发新生干货，只软植入 |
| 回复太商业化 → 学长人设崩塌 | 口语化、带表情、不用营销字眼 |
| 合作到期后人设绑定 | 不把驾校名写进ID/简介，到期删植入即可 |

## 禁忌
- 驾校内容占比不超过10%
- 不用「限时优惠」「名额有限」等营销词汇
- 不把驾校名写进ID或简介
