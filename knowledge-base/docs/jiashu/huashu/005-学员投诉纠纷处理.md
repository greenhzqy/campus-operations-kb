# 学员投诉纠纷处理

## 场景
学员报名后产生不满来投诉——教练态度差、收费有争议、要求退费、情绪激动纠缠不休。这是最关键的高风险场景，必须严格执行「甩锅不调解」原则。

## 话术

**版本A · 教练态度问题：**

> 啊这样啊，不好意思让你体验不好😥 这个事我确实没办法直接处理，我只是帮忙推荐的。你直接找驾校负责人反映，他们处理效率比我快👉 [推送代理微信或客服微信]

**版本B · 收费争议：**

> 费用的事我不太清楚他们的最新政策，你直接联系驾校财务或者负责人核实一下，我这边没有经手任何费用。👉 [推送代理微信]

**版本C · 要求退费：**

> 退费这个事我处理不了哈，我没经手你的报名费。你直接联系驾校那边走正规流程，该退的他们肯定会退的。👉 [推送代理微信]

**版本D · 对方情绪激动/纠缠不休：**

> 理解你的心情，但我确实只是帮忙介绍了一下，具体的服务、收费、合同都是你和驾校之间的事情。你直接找他们负责人沟通，他们必须给你一个说法。我这边能做的就是帮你转达一下，效果不如你自己直接找他们。

## 四字原则
**共情 → 划界 → 推微信 → 闭嘴**

1. 第一时间表示理解（共情但不认错）
2. 明确表态「我不经手费用/我只是推荐」（划清边界）
3. 光速推送代理微信（转移对象）
4. 不做任何承诺（不说「我帮你去说说」）

## 禁忌
- 绝不承诺「我帮你说说」「我让他们给你解决」
- 对方继续纠缠 → 不再回复新的实质内容，最多回复「你直接联系驾校就行哈」
- 不公开撕、不在评论区对线
- 不承认任何责任
