# 团报优惠和拿证时间

## 场景
新生问「和室友一起报有优惠吗」「最快多久拿证」「练车怎么安排」「和上课会冲突吗」。

## 话术

> 团报一般有优惠的，具体优惠多少看你几个人。拿证的话正常练车大概一两个月，快的一个多月也有。
>
> 他们练车是提前一天约时间，不会耽误上课，这点我觉得挺方便的。你可以加负责人问团报价👉 [推送代理微信]
>
> 记得说是学长推荐的哈，可能会额外照顾一下🤝

## 要点
- 给模糊范围，不给精确承诺（「大概一两个月」而非「XX天必拿证」）
- 引导加代理微信获取具体优惠
- 轻松的语气 + 表情符号保持学长人设

## 禁忌
- 不给精确的拿证时间承诺（如「30天包拿证」）
- 不承诺具体优惠金额
- 不用「名额有限」「赶紧」等制造紧迫感的字眼
