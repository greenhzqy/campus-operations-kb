# 对方觉得贵或犹豫

## 场景
用户对报价表示犹豫或直接说"太贵了""能不能便宜点"。

## 话术 / 要点
"这本确实用得比较多，笔记也认真。你要觉得贵的话我再便宜5块，20拿走～反正放我这也占地方。

或者你看看还有没有其他需要的，多买几本我给你打包价 👇 **【发其他书单】**"

### 应对策略
- **小额让步**：降价5-10元，给面子又不伤利润
- **打包优惠**：引导多买几本，用打包价提升客单价
- **制造紧迫感**：暗示库存有限或"放我这也占地方"

## 禁忌
- 不要一上来就大幅度降价，先小额让步
- 不要贬低书的品质来合理化降价
- 不要表现出急于出手的姿态
