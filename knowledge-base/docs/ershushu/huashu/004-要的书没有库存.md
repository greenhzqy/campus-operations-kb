# 要的书没有库存

## 场景
用户询问的教材当前已售罄或无库存，需维护关系并保持后续转化可能。

## 话术 / 要点
"这本目前没有了，不过我可以帮你留意一下。你留个微信/QQ，收到的话第一时间告诉你。

或者你可以问问XX专业的学长，他们那边可能也有～"

### 关键动作
- **承诺留意**：让对方感受到被重视
- **留联系方式**：把公域咨询沉淀到私域
- **推荐替代渠道**：体现利他心态，不拘泥于自己的库存

## 禁忌
- 不要说"没了"就结束对话，必须给后续方案
- 不要承诺一定收到（控制预期）
- 不要为了成交推荐不相关的书
