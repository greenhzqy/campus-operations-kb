# 书况争议售后处理

## 场景
用户收到书后对书况不满意，认为与实际描述不符，要求退换或补偿。

## 话术 / 要点
"不好意思啊，可能我当时没拍清楚……这本确实是正常使用的痕迹，不是损坏。你看这样，这本我再便宜5块，或者你下次要其他书我优先给你留着，行不？"

### 处理原则
1. **小额让步（5-10元）**：维护口碑，不纠缠
2. **大金额争议**：退书退款，不纠缠
3. **底线**：不坐班、不处理纠纷、尽量不碰钱

### 预防措施
- 卖前必须如实拍照+说明笔记程度
- 大幅破损的书坚决不卖
- 售前确认书况，售后售出不退不换（但小额可让步）

## 禁忌
- 不要和买家争吵谁对谁错
- 不要在公开评论区处理争议，转私信
- 不要为小额争议消耗过多时间
