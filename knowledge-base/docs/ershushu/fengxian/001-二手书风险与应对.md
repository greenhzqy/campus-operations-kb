# 二手书风险与应对

## 场景
识别二手书业务中的常见风险，掌握对应的预防和应对方法。

## 要点

| 风险 | 应对 |
|------|------|
| 教材版本更新 | 卖书前确认对方课程使用的版本，不确定就让对方问老师/学长 |
| 快递损坏 | 拍照留存发货前书况，快递损坏由发货方承担 |
| 收款争议 | 小额（≤20元）直接退还，保留口碑 |
| 书况不符 | 卖前如实拍照+说明笔记程度，大幅破损的书不卖 |
| 学校发新书 | 新生入学后学校统一采购 → 窗口期缩短，需在发书前完成销售 |
| 库存积压 | 限收畅销品种，冷门专业课教材不收 |

## 禁忌
- 不要卖大幅破损的书（售出必有争议）
- 不要为小额收款争议纠缠太久（口碑比20元重要）
- 不要收冷门专业课教材（周转慢、积压风险高）
