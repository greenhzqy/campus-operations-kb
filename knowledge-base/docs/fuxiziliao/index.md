# 复习资料知识库

## 业务概述

复习资料是二手书业务的**自然延伸**——除了卖教材，还可以卖期末考试复习资料。这批资料覆盖重邮大一/大二高频课程的期末试卷、复习笔记、课后答案，是新生期中期末复习的刚需品。

- **定位**：大学课程期末复习资料（试卷+笔记+题库）
- **目标用户**：大一/大二学生（期中期末考前1-2周需求最强）
- **核心窗口**：期中前（10月/4月）、期末前（12月/6月）
- **定价策略**：单科5-15元，打包价更优惠
- **红线**：不碰盗版教材电子版（版权风险），仅分享历年试卷和学生笔记

## 为什么复习资料是好生意

1. **需求确定**：每个学生都要期末考试，每个考试都需要复习资料
2. **时效性强**：考前2周是刚需窗口，转化速度极快
3. **边际成本低**：一份资料卖给多个人，成本接近零
4. **协同效应**：买二手书的学生自然需要复习资料，反之亦然
5. **信任积累**：卖靠谱的资料 → 信任加深 → 更可能报驾校/办校园卡
