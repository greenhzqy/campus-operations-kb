# 资料销售策略

## 场景
手头有复习资料，怎么卖出去、怎么定价、怎么和二手书/驾校/校园卡联动。

---

## 一、定价策略

### 单科定价

| 资料类型 | 建议售价 | 说明 |
|---------|---------|------|
| 单科历年试卷（1-3套） | 5-8元 | 电子版直接发，零成本 |
| 单科复习笔记 | 8-12元 | 内容越多越贵 |
| 单科试卷+笔记打包 | 10-15元 | 推荐！学生觉得划算 |
| 全套（所有科目） | 30-50元 | 大一上全套最有吸引力 |

### 定价原则
- **电子版为主**：零边际成本，售价可以低，走量
- **"一杯奶茶钱"心理**：5-15元的定价不过分，学生下单无压力
- **打包更有吸引力**："一科10块，三科打包25，五科打包35"
- **团购优惠**："两个人一起买每人减2块，三个人一起每人减3块"

## 二、销售渠道

### 抖音/小红书（公开流量）
```
发"期末复习攻略"类内容 → 评论区引导"需要复习资料的私信我" → 私信成交
```

**内容选题**：
- "大一期末怎么复习？学长的血泪经验"
- "这3门课一定要提前准备，不然期末会哭"
- "重邮C语言期末考什么？真题分析"

### 新生群/QQ群（私域流量）
```
群里帮新生答疑 → 自然提到"我这边有一些复习资料" → 加好友 → 发资料目录
```

**关键**：不要在群里直接卖，要先提供价值（帮答疑）再自然过渡。

### 二手书联动
```
买二手书的学生 → 顺带问"要不要这个课的复习资料？有历年试卷" → 加购
```

**公式**：每卖出一套二手教材，至少有50%概率能卖出一份对应复习资料。

---

## 三、捆绑销售策略

### 和二手书捆绑
| 捆绑组合 | 内容 | 建议价 |
|---------|------|--------|
| 教材 + 资料包 | 二手教材 + 该课试卷+笔记 | 教材价+10元 |
| 大一上全包 | 全部必修课教材 + 全部复习资料 | 一口价 |

**话术**："这本书25，另外这门课的期末试卷和学霸笔记我这边也有，加10块一起给你，复习的时候能省好多时间～"

### 和驾校/校园卡联动
- 已经在你这里办了校园卡/报了驾校的学生 → 复习资料可以作为**福利赠送**
- "感谢信任，送你一套高数复习资料，期末用得上 😄"
- 低成本维护关系，提高转介绍率

---

## 四、运营节奏

| 时间 | 动作 | 重点 |
|------|------|------|
| 开学第1-2周 | 卖教材时顺带提复习资料 | 不要主推，顺带 |
| 第8-10周（期中前） | 发"期中复习攻略"内容，推复习资料 | 第一次需求小高峰 |
| 第14-16周（期末前） | 🔥 **全力推复习资料**，各渠道铺开 | 一年中需求最大的窗口 |
| 期末后 | 收新的试卷和笔记，补充资料库 | 从学弟学妹那收 |

---

## 五、资料交付

```
对方付款 → 微信/QQ发电子版PDF → 确认收到 → 结束
```

- 电子版直接发，无物流成本
- 如果需要打印版，加收打印费+配送费
- 发完后可以说一句"有问题随时问我，考试加油💪"

---

## 禁忌
- 不要在公开平台直接发"XX课真题"，可能触发学校关注
- 不要承诺"保证考到XX分"（合规风险）
- 注意版权：教材电子版（出版社有版权的）不要公开售卖
- 不要为了卖资料而贩卖焦虑（"不买肯定挂科"之类的话术）
- 小金额交易走微信/支付宝即可，不要搞复杂
